## 대표 구조

| 코드 | 이름 | 대표로 고르는 조건 |
| --- | --- | --- |
| PS01 | 직접 계산형 | 알려진 절차를 바로 적용 |
| PS02 | 식 구성·모델링형 | 문장·도형 조건을 수식으로 변환 |
| PS03 | 동치 변형형 | 해집합을 보존하며 식을 변형 |
| PS04 | 치환·구조 단순화형 | 복잡한 대상을 간단한 형태로 변환 |
| PS05 | 역추론형 | 목표 결과에서 필요한 조건을 역으로 탐색 |
| PS06 | 조건 결합형 | 여러 조건의 공통 만족 범위를 도출 |
| PS07 | 경우 분류형 | 조건에 따라 해법을 분기 |
| PS08 | 관계 추론형 | 대상 사이의 수학적 관계를 활용 |
| PS09 | 함수·그래프 해석형 | 그래프의 성질로 문제를 해결 |
| PS10 | 기하 구조 활용형 | 도형의 관계와 정리를 적용 |
| PS11 | 최적화형 | 최댓값·최솟값의 발생 조건을 탐색 |
| PS12 | 존재·개수 판정형 | 조건을 만족하는 대상의 존재·개수 결정 |
| PS13 | 규칙성·일반화형 | 반복되는 규칙을 발견하고 일반화 |
| PS14 | 논리·증명형 | 명제의 참·거짓이나 필연성을 증명 |
| PS15 | 구성·보조 요소 도입형 | 보조선·보조변수·보조함수를 도입 |
| PS16 | 복합·다단계 연결형 | 서로 다른 핵심 전략을 연결 |
