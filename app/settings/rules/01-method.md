# 풀이 구조 분류

수학 문항을 풀이 구조 코드로 분류할 때 이 문서만 기준으로 삼는다.
단원 이름, 공식 이름, 계산 결과가 아니라, 정답을 결정하는 지배적인 사고 작용을 본다.
정답을 계산하거나 풀이 과정을 적지 않는다. 보이지 않거나 판독하지 못한 풀이는 추정하지 않는다.

## 붙이는 네 층

한 문항에 아래 네 층만 붙인다. 층마다 쓰는 코드가 다르다.

| 층 | 개수 | 코드 | 고르는 대상 |
| --- | --- | --- | --- |
| 대표 구조 | 1 | PS01–PS16 | 풀이를 지배하는 사고 |
| 보조 구조 | 0개 이상 | PS01–PS16 | 실제로 쓰였으나 지배적이지 않은 사고 |
| 세부 코드 | 실제로 쓴 것만 | A01–F12 | 그 사고 안에서 수행한 동작 |
| 의존 관계 | 1 | R01–R05 | 단계가 이어지는 방식 |

코드만 적는다. 여러 개면 쉼표로 구분한다. 이름과 설명을 코드 자리에 섞지 않는다.
대표와 같은 PS를 보조에 다시 적지 않는다.

## 고르는 순서

1. 주어진 정보, 요구하는 결과, 풀이의 결정적 전환을 먼저 정한다.
2. PS 표에서 그 전환에 맞는 코드 1개를 대표로 고른다.
3. 같은 문항에서 분명히 수행되지만 대표가 아닌 PS만 보조로 붙인다.
4. 세부 코드는 풀이에서 실제로 일어난 동작만 붙인다. 그 단원에 있을 법한 동작을 넣지 않는다.
5. 단계가 이어지는 방식 중 가장 두드러진 것 1개를 R로 고른다.
6. PS가 둘 이상 비슷하면 아래 7가지로 가른다. 그래도 남으면, 답을 최종적으로 확정하는 쪽을 대표로 둔다.

한 전략이 답을 결정하면 그 PS가 대표이고 나머지는 보조다.
서로 다른 핵심 전략을 잇는 연결 자체가 결정적 전환일 때만 대표를 PS16으로 두고, 이어진 전략은 보조로 둔다.

PS 16개는 서로 배타적이지 않다. 한 문항이 여러 PS에 해당할 수 있다.
같은 연산을 공유해도 목표, 분기, 검증이 다르면 같은 구조가 아니다. 공유한 코드는 세부 코드에 적고, 대표는 각 문항의 지배적 사고로 둔다.

## 같은 구조인지 가르는 7가지

아래 7가지가 같아야 같은 풀이 구조다. 하나라도 다르면 같은 대표 구조로 묶지 않는다.

| 순서 | 기준 | 확인할 질문 | 코드에 반영하는 곳 |
| --- | --- | --- | --- |
| 1 | 입력 조건 | 어떤 수학적 정보가 주어지는가 | 조건의 종류와 역할. B 코드 |
| 2 | 목표 | 무엇을 구하거나 증명하는가 | 값, 범위, 개수, 참·거짓. 대표 PS |
| 3 | 핵심 발상 | 해결의 결정적 전환은 무엇인가 | 대표 PS 1개 |
| 4 | 연산 단계 | 어떤 동작을 수행하는가 | 세부 코드 |
| 5 | 의존 관계 | 어떤 단계가 먼저 끝나야 하는가 | R 코드 1개 |
| 6 | 분기 구조 | 경우를 나누거나 합쳐야 하는가 | C 코드, 필요하면 R03 |
| 7 | 검증 방식 | 결과를 무엇으로 확정하는가 | 대입, 반례, 범위, 등호 성립 |

## 자주 갈리는 경계

| 경계 | 대표를 이렇게 가른다 |
| --- | --- |
| PS01과 PS04 | 알려진 절차를 그대로 적용하면 PS01. 대상을 단순한 형태로 바꾼 뒤 되돌려야 하면 PS04. |
| PS03과 PS04 | 해집합을 유지한 채 식을 고치면 PS03. 새 변수나 단순 구조로 바꾸면 PS04. |
| PS02와 PS06 | 문장·도형 조건을 식으로 옮기는 일이 중심이면 PS02. 이미 있는 조건의 공통·합·배제가 답을 정하면 PS06. |
| PS06과 PS12 | 만족 범위가 목표면 PS06. 존재 여부나 개수가 목표면 PS12. 범위를 구한 뒤 개수를 세면 대표는 PS12, 보조는 PS06. |
| PS07과 PS12 | 경우 분할 자체가 해법이면 PS07. 나눈 뒤 개수가 목표면 대표는 PS12, 보조는 PS07. |
| PS08과 PS09 | 대상 사이의 관계식이 중심이면 PS08. 그래프의 성질로 읽으면 PS09. |
| PS10과 PS15 | 도형의 관계·정리 적용이 중심이면 PS10. 보조선·보조변수·보조함수를 새로 도입하는 일이 결정적이면 PS15. |
| PS05와 R05 | PS05는 사고의 종류다. R05는 단계가 목표에서 거꾸로 이어진다는 의존 관계다. 함께 붙일 수 있다. |
| PS11과 F01–F05 | 극값이 목표면 대표는 PS11. F01–F05는 그 동작이다. |
| PS14와 F06–F09 | 참·거짓·필연이 목표면 대표는 PS14. 반례·대우·귀류·귀납은 세부 코드다. |
| PS13과 F10–F12 | 반복 규칙의 일반화가 목표면 대표는 PS13. 점화식·규칙 추론·일반항은 세부 코드다. |
| PS16과 보조 구조 | 지배적인 전략이 하나면 그 PS가 대표다. 연결 자체가 핵심일 때만 PS16. |
